# Monty — Data Analytics Sessions

Python teaching notebooks from the Data Analytics class sessions. Each notebook is
written to be read top-to-bottom and run cell by cell, with plain-language
explanations in the text cells and heavily commented code cells.

## Contents

| File | Topics |
|---|---|
| `Intro.ipynb` | `print()`, `input()`, variables, naming conventions, primitive data types (`int`, `float`, `str`, `bool`, `None`), `type()` |
| `String.ipynb` | Checking types, strings and quoting, casting `input()` with `int()`, concatenation, f-strings, string length |
| `intro.pdf` | PDF export of the intro session |

## How to run

```bash
pip install notebook
jupyter notebook
```

Then open any `.ipynb` file and run the cells with `Shift + Enter`.
